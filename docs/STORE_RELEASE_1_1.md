# Store Release 1.1.0

## Release notes

Impulse checkout now supports locally saved masked card profiles and shipping
or billing addresses. Add and select checkout profiles directly during a
simulated order or manage them from Settings. Complete card numbers are never
saved or transmitted, card security codes are never requested, and no payment,
purchase, or delivery occurs.

## Store checklist

- Deploy the updated public privacy policy before submitting the mobile build.
- Replace the checkout screenshot with one showing the new profile selectors
  and the visible simulator disclaimer. Never use real personal information in
  store screenshots.
- Keep Google Play's Financial features declaration set to no financial
  features because the app neither accepts nor processes payments.
- Re-review Google Play Data Safety and Apple App Privacy answers. The new
  checkout details are processed only on the device and are not sent to the
  developer or a third party.
- Upload Android version code 2 and iOS build number 2 as version 1.1.0.
